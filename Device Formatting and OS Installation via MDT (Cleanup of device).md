
 Device Formatting and OS Installation via MDT (Cleanup of device).


Objectives:
 To define a standard process for formatting a device and reinstalling the operating system using MDT.
Scope:
 This SOP applies to all IT support engineers involved in system setup or refurbishment using MDT.
Responsibilities:
 IT engineers must follow this SOP to ensure devices are correctly formatted and configured before being issued to users.
Procedure:
 Follow the steps outlined below. Each step includes a screenshot with a brief description of the required action.

 Step-1:
   Restart the device.

Step-2:
Continuously press the F12 key to enter Boot Mode.

Step-3:
Select 'PXE Boot' and press Enter.




Step-4:
 On the screen, select 'Run the Deployment Wizard to install a new operating system'.
