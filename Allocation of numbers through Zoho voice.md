

## 1. Purpose

This SOP outlines the process for allocating Zoho Voice numbers to users upon receiving a valid request or ticket. The objective is to ensure proper approval and consistent handling of number allocation requests.

## 2. Scope

This procedure applies to all employees who require a Zoho Voice number for official communication purposes.

## 3. Responsibilities

- **Requestor:** Raises a ticket requesting a Zoho Voice number.
- **IT Support Team:** Validates approval, checks number availability, and assigns numbers in Zoho Voice.
- **Reporting Manager:** Provides approval for number allocation.

## 4. Procedure

### Step 1: Ticket Verification

- Receive a ticket raised by the user requesting a Zoho Voice number.
- Verify that the ticket contains the following details:
  - User name and department
  - Justification for the number allocation
  - Preferred number, if any

### Step 2: Approval Confirmation

- Request approval from the user’s reporting manager via email or ticket comment.
- Proceed only after receiving the manager’s approval confirmation.

### Step 3: Login to Zoho Voice

- Access the Zoho Voice Portal using admin credentials.
- Navigate to the **Numbers** section under the admin console.

### Step 4: Check Available Numbers

- Review the list of available numbers in the Zoho Voice console.
- If the user has requested a specific number:
  - Check whether the requested number is available.
  - If available, proceed to assign it.
  - If unavailable, select an available number from the list.

### Step 5: Assign the Number

- Assign the chosen number to the requested user’s Zoho account.
- Ensure that the number is properly configured and activated.
- Update internal records with the assigned number.

### Step 6: Update Ticket and Notify User

- Update the ticket with the details of the assigned number.
- Notify the user via a ticket response or email that the number has been successfully assigned.
- Close the ticket after receiving the user’s acknowledgment.

## 5. Notes

- Ensure that no number is assigned without proper managerial approval.
- Maintain a record of all allocated numbers for audit and reference.
- Follow data privacy and company communication policies.
