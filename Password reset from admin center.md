# Password Reset from Admin Center

**SOP Description:** Guide to reset password from 365 Admin Center.

**Role:** Need to be a User Administrator.

## Procedure

1. Open the Microsoft 365 Admin Center.

2. Navigate to **Users → Select the user**.

3. Select **Reset Password**.

4. Choose **Automatically create a password** and reset the password.

5. Verify if the password has been reset.
