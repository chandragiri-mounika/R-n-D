# Sophos Connect – VPN Setup

## Steps to Download and Setup SSL VPN

Navigate to one of the following URLs based on which location to connect to.

- **For HYD VPN:** https://hydsecure.genzeon.com
- **For PUN VPN:** https://punsecure.genzeon.com
- **For US VPN:** https://extsecure.genzeon.com

### Step 1: Login via Single Sign-On (SSO)

- Login via Single Sign-On (SSO).
- On the login page, click Single Sign-On and select your Genzeon account.
- If installed, you should see the Sophos Connect icon in the system tray (bottom-right corner of your desktop).

### Step 2: Install Sophos Connect

If Sophos Connect is not pre-installed on your system, please install it from the Self-Service Portal.

### Step 3: Download the SSL VPN Configuration File

- Download the appropriate SSL VPN configuration file.

### Step 4: Import the VPN Configuration File

- Open Sophos Connect.
- Click Import Connection.
- In the File Explorer window, navigate to your Downloads folder.
- Select the downloaded configuration file.

### Step 5: Connect to VPN

- Here we must click on connect.

### Step 6: Authenticate Using SSO

- Click on Single Sign-On (SSO).
- Once authenticated, you will be connected to the secure VPN.
