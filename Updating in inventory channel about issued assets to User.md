Updating in inventory channel about issued assets to User
SOP Description
process for updating issued assets in the Microsoft Teams inventory channel 

Any updates to the inventory must be posted on the Inventory Channel under IT Operations Team - Inventory | IT Operations | Microsoft Teams

	1. Whenever an asset is issued to new user, please update it in the inventory channel by tagging @inventory Update. The update should include the following details:
	•  Ticket number and ticket title (in the subject line)
	•   Asset tag
	•   Serial number
	•    Username
	• Which assets were issued to the user
	



	2. You can also post updates by submitting the below Microsoft Form:

IT Asset Assignment Record – Fill out form
