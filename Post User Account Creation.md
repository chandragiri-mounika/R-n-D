# Post User Account Creation

**SOP Description:** This explains how to run the post-user creation tasks after creating the user account.

## 1. Execute the Post-User Creation Script

Run the following PowerShell script:

```powershell
Set-PostUserCreation -FirstName $FirstName -LastName $LastName
```

After running the above script, for example, the Username :- Vijay Hanumanthu

## 2. Office 365 Group Membership

The user will be added into the following Office 365 groups:

a. KnowBe4Access.

b. AllPhilippinesAssociates

c. AllUSAssociates

d. AllIndiaAssociates
