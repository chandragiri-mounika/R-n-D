
# Snipe-IT Data Management Attributes

This document outlines the standard attributes that must be maintained in Snipe-IT for Assets, Licenses, and Accessories to ensure accurate asset tracking and management.

## 1. Asset Attributes

The following are the standard Asset Attributes that must be maintained in Snipe-IT:

| S.No | Attribute Name |
|---:|---|
| 1 | Serial Number |
| 2 | Manufacturer |
| 3 | Category |
| 4 | Model |
| 5 | Model Number |
| 6 | Purchase Cost |
| 7 | Location |
| 8 | Supplier |
| 9 | Warranty |
| 10 | Purchase Date |
| 11 | Status |
| 12 | Physical Memory |
| 13 | Storage |
| 14 | CPU |

## 2. License Attributes

The following are the standard License Attributes that must be maintained in Snipe-IT:

| S.No | Attribute Name |
|---:|---|
| 1 | License Name |
| 2 | Category |
| 3 | Purchase Cost |
| 4 | Product Key |
| 5 | Seats |

## 3. Accessory Attributes

## 4. Important Notes

- Ensure all applicable attributes are updated correctly in Snipe-IT.
- Maintain accurate and consistent information for all assets, licenses, and accessories.
- Verify the details before saving or updating records.
- Update the information whenever changes occur.
