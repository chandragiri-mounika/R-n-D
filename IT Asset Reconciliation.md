# IT Asset Reconciliation

## 1. Purpose

The purpose of this SOP is to define the standardized process for conducting IT Asset Reconciliation to ensure that all assigned assets are verified, tracked, and updated accurately in the asset management system (Snipe-IT).

## 2. Scope

This procedure applies to all IT assets (laptops, desktops, peripherals, etc.) assigned to employees across the organization. The process is initiated whenever a service ticket for asset reconciliation is raised.

## 3. Responsibilities

- **IT Asset Team:** Responsible for initiating and executing the reconciliation process, maintaining the reconciliation records, and updating Snipe-IT.
- **End Users:** Responsible for confirming the assigned asset details when contacted by the IT team.
- **IT Lead / Supervisor:** Responsible for reviewing and approving reconciliation completion and ensuring ticket closure.

## 4. Tools and Resources

- Snipe-IT (Asset Management Tool)
- Microsoft Excel (for reconciliation tracking)
- Microsoft Teams (for communication and verification calls)
- Service Desk Ticketing System (for tracking and closing reconciliation tasks)

## 5. Procedure

### Step 1: Ticket Initiation

- Receive a service ticket for IT Asset Reconciliation through the service desk system.

### Step 2: Export Asset Data

- Log in to Snipe-IT.
- Export the list of assigned assets into an Excel sheet.
- Save the file with a standard naming it according to the Ticket wise.

### Step 3: Verification with End Users

- For each user listed, initiate communication via Microsoft Teams (chat or call).
- Confirm the following details with the user:
  - Asset Tag / Device Tag
  - Device and Serial Number
- If confirmed, mark the record as “Verified” in the Excel sheet.
- If mismatch/ mark it as Mismatch will investigate on the issue and change the Inventory details in snipe-IT accordingly.

### Step 4: Update Reconciliation Sheet

- Add remarks in the “Comments” column for each user (e.g., Verified etc.).
- Once all users are verified, review the sheet for completeness and accuracy.

### Step 5: Attach and Close Ticket

- Attach the finalized reconciliation Excel sheet to the corresponding service ticket.
- Add a note summarizing total users verified.
- Then close the ticket upon validation.
