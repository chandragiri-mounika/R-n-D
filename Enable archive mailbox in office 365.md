Enable archive mailbox in office 365
SOP Description

Manually enabling mailbox from 0365 Admin Center
Enabling the archive requires Exchange Admin rights
1) Open the Exchange Admin Center (EAC)


2) Go to Recipients → Mailboxes


3) Find the User






4) Open User Properties and Locate Archive Setting



5) Enable (Toggle) the Archive Mailbox


6) Verify Status by refreshing the page
